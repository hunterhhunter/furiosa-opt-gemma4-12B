# Experiment README template

This file documents the sections generated by `optcycle.render`:

- experiment identity, kernel, state, and hypothesis
- source fingerprints and candidate patch
- baseline/candidate schedule and static review
- Arena attempts and measured cycles
- final decision, next command, and event timeline

The generated README is a derived index. `manifest.json` and `events.jsonl` remain
the machine-readable sources of truth.
